# Intent: NISA vs 特定口座 税金比較機能

**プロジェクト**: 002-nisa-tax-comparison（001 の機能拡張）
**作成日**: 2025-11-18
**実装方法**: 001-nisa-simulator に「税金比較」タブを追加

---

## Intent（インテント）

### 目的
NISA（少額投資非課税制度）の最大のメリットである**非課税効果**を、特定口座との比較を通じて具体的な金額で視覚化し、ユーザーが NISA の節税効果を直感的に理解できるようにする。

### 背景
- NISA 制度は「税金がかからない」とは知っていても、**具体的にいくら得するのか**が分かりにくい
- 特定口座では運用益に対して **20.315% の税金**が課される
- 長期運用では税金の差が数百万円単位になるが、その金額が見えないため NISA の価値を実感しにくい
- 投資初心者が NISA 口座開設の判断材料として、具体的な節税額を知りたい

### 期待される成果
- **ユーザーにとっての価値**: NISA の節税効果を具体的な金額（例: 「200万円お得」）で確認でき、NISA 口座開設の動機付けになる
- **教育的価値**: 税金が運用成績に与える影響を視覚的に理解でき、長期投資における税制優遇の重要性を学べる
- **意思決定の支援**: NISA と特定口座のどちらを選ぶべきか、データに基づいて判断できる

### 成功した未来の状態
ユーザーが「毎月 3 万円、20 年間、年利 5% で積み立てた場合、NISA なら税金 0 円だが、特定口座だと約 100 万円の税金がかかり、手取りが 100 万円少なくなる」という具体的な数値を確認し、「NISA 口座を絶対開設しよう！」と確信を持って行動できるようになった。税金の差額を視覚的に理解し、NISA 制度の価値を実感するユーザーが増えた。

## 計算ロジック

### NISA の場合
```
総資産 = 元本 + 運用益
税金 = 0円
手取り総資産 = 総資産
```

### 特定口座の場合
```
総資産（税引前） = 元本 + 運用益
税金 = 運用益 × 20.315%
手取り総資産 = 総資産（税引前） - 税金
```

### 差額
```
節税額 = 特定口座の税金 - NISA の税金
      = 運用益 × 20.315% - 0
      = 運用益 × 20.315%
```

  nisa: {
    totalAssets: number;

    netAssets: number;  // totalAssets と同じ
  };
  tokutei: {
    totalAssets: number;  // 税引前
    tax: number;  // 運用益 × 0.20315
    netAssets: number;  // totalAssets - tax
  };
  difference: number;  // nisa.netAssets - tokutei.netAssets
}

export function calculateTaxComparison(plan: InvestmentPlan): TaxComparisonResult

## Scope（スコープ）

### 対象範囲
- NISA vs 特定口座の税金比較
