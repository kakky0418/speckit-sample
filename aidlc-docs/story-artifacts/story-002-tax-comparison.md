# User Story: NISA vs 特定口座 税金比較

**Story ID**: US-002-001
**Priority**: P1 (MVP)
**Status**: Draft
**Created**: 2025-11-18

---

## Story Statement

**As a** 投資初心者または NISA 口座開設を検討しているユーザー
**I want to** NISA と特定口座の税金の差を具体的な金額とグラフで確認したい
**So that** NISA の節税効果を理解し、口座開設の判断材料にできる

---

## Goal（達成したいこと）

- NISA の節税効果を**具体的な金額**（例: 「100万円お得」）で確認できる
- **4種類のグラフ**で多角的に税金の差を理解できる
- 001 のシミュレーション結果から**1クリック**で税金比較に遷移できる
- NISA と特定口座の違いが**一目でわかる**

---

## Why this priority（なぜこの優先度か）

- NISA の**最大のメリット（非課税）**を視覚化する重要機能
- 001 の基本シミュレーションを補完し、ユーザーの投資判断を支援
- 税金の差額は数十万〜数百万円にな

るため、ユーザーにとって価値が高い
- 教育的価値が高く、NISA 制度の理解促進に貢献

---

## Acceptance Criteria（受け入れ基準）

### AC-1: 節税額の強調表示
**Given** ユーザーが基本シミュレーションで条件を入力済み（例: 毎月3万円、20年、年利5%）
**When** 「税金比較」タブをクリックする
**Then** 以下が表示される:
- 💰 アイコン付きで「NISA の節税効果」というタイトル
- 具体的な節税額（例: 「1,041,895円」）が大きく表示される
- 「特定口座なら税金で失う金額」というサブタイトル

---

### AC-2: 手取り金額の比較表示
**Given** 税金比較タブが表示されている
**When** ページをスクロールまたは確認する
**Then** 以下が並列表示される:
- NISA の手取り総資産（例: 12,330,000円）
- 特定口座の手取り総資産（例: 11,288,105円）
- 差額（例: △1,041,895円）が明示される

---

### AC-3: 積み上げ棒グラフの表示
**Given** 税金比較タブが表示されている
**When** グラフセクションを確認する
**Then** 以下の積み上げ棒グラフが表示される:
- **NISA**: [元本（青）][運用益（緑）]
- **特定口座**: [元本（青）][運用益（暗緑）][税金（赤）]
- 各セクションにマウスホバーで金額が表示される
- 凡例が表示される

---

### AC-4: 年次推移グラフの表示
**Given** 税金比較タブが表示されている
**When** 年次推移グラフを確認する
**Then** 以下が表示される:
- X軸: 年数（0年〜20年）
- Y軸: 総資産額（手取り）
- 青線: NISA の手取り総資産
- 赤線: 特定口座の手取り総資産
- 2本の線の差が年々開いていく様子が視覚化される
- 凡例が表示される

---

### AC-5: 詳細内訳テーブルの表示
**Given** 税金比較タブが表示されている
**When** 詳細内訳セクションを確認する
**Then** 以下のテーブルが表示される:

| 項目 | NISA | 特定口座 |
|------|------|----------|
| 元本合計 | 7,200,000円 | 7,200,000円 |
| 運用益（税引前） | 5,130,000円 | 5,130,000円 |
| 税金（20.315%） | **0円** | **1,041,895円** |
| 手取り運用益 | 5,130,000円 | 4,088,105円 |
| **総資産（手取り）** | **12,330,000円** | **11,288,105円** |

---

### AC-6: 001 からの遷移
**Given** ユーザーが 001 の基本シミュレーションで条件を入力済み
**When** 「税金比較」タブをクリックする
**Then**:
- 入力条件（積立額、期間、利回り）がそのまま引き継がれる
- React Context 経由でデータが共有される
- ページ遷移が即座に完了する（< 500ms）

---

### AC-7: レスポンシブ対応
**Given** ユーザーがモバイルデバイスで閲覧している
**When** 税金比較タブを表示する
**Then**:
- 4つのグラフが縦スクロールで表示される
- 各グラフが画面幅に合わせて調整される
- テキストサイズが適切に調整される

---

### AC-8: エッジケース - 運用益がマイナス（元本割れ）
**Given** ユーザーがマイナス利回り（例: -3%）を入力
**When** 税金比較タブを表示する
**Then**:
- 運用益がマイナスの場合、税金は 0円 と表示される
- NISA も特定口座も手取り総資産が同じになる
- 節税額は 0円 と表示される

---

### AC-9: エッジケース - 運用益が 0円
**Given** ユーザーが利回り 0% を入力
**When** 税金比較タブを表示する
**Then**:
- 税金は 0円 と表示される
- NISA も特定口座も手取り総資産が同じ（元本のみ）
- 節税額は 0円 と表示される

## Independent Test（独立テスト方法）

### テストシナリオ
1. 001 のメインページで以下を入力:
   - 毎月の積立額: 30,000円
   - 積立期間: 20年
   - 想定年利回り: 5%

2. 「計算する」ボタンをクリック

3. 「税金比較」タブをクリック

4. 以下が表示されることを確認:
   - 💰 節税額: **約1,041,895円**
   - NISA 手取り: **12,330,000円**
   - 特定口座 手取り: **11,288,105円**
   - 4種類のグラフが正しく表示される

### 期待される結果
- すべてのグラフと数値が正確に計算・表示される
- 税率 20.315% が正しく適用される
- UI が直感的で分かりやすい

### 計算ロジック
```typescript
interface TaxComparisonResult {
  nisa: {
    totalAssets: number;
    tax: number;  // 常に 0
    netAssets: number;
  };
  tokutei: {
    totalAssetsBeforeTax: number;
    tax: number;  // 運用益 × 0.20315
    netAssets: number;
  };
  taxSavings: number;  // nisa.netAssets - tokutei.netAssets
}
```

## Risks & Mitigations（リスクと対策）

### Risk 1: グラフが多すぎて分かりにくい
**対策**: グラフの順序を最適化し、節税額を最上部に配置

### Risk 2: React Context の実装が複雑化
**対策**: シンプルな Context 設計、必要最小限の状態のみ管理

### Risk 3: 税率計算の誤差
**対策**: ユニットテストで計算精度を検証
