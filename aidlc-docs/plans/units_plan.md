## ⚠️ 重要な決定が必要な箇所

以下の点について、作業中にあなたに確認を求めます:

1. **ユニット分割の粒度**:
   - 3ユニット（計算/UI/可視化）で十分か？
   - より細かい分割が必要か？

2. **技術的境界の定義**:
   - バックエンド/フロントエンドの分離は必要か？
   - モノリシックフロントエンドで良いか？

3. **並列開発の優先度**:
   - すべてのユニットを並列開発するか？
   - MVP 優先で順次開発するか？

4. **インターフェース設計の詳細度**:
   - API レベルまで定義するか？
   - 概念レベルで留めるか？
