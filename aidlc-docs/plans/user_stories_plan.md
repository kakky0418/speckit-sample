## 📋 高レベル要件（製品説明）

**製品名**: NISA積立シミュレーター

**製品概要**:
NISA（少額投資非課税制度）を活用した積立投資の将来シミュレーションを提供する Web アプリケーション。投資初心者が毎月の積立額と期間を入力し、複利計算による将来資産額を確認できる。

**主な機能**:
1. 基本的な積立シミュレーション（毎月の積立額、期間、利回り入力）
2. NISA投資枠の活用状況表示
3. 複数の運用シナリオ比較（保守的/標準/楽観的）

**技術スタック**: Next.js 14+, React 19, TypeScript, Chart.js, bun
