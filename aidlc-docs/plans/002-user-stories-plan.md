## 📋 高レベル要件（製品説明）

**製品名**: NISA vs 特定口座 税金比較機能

**製品概要**:
NISA（少額投資非課税制度）の最大のメリットである非課税効果を、特定口座との比較を通じて具体的な金額で視覚化する。001-nisa-simulator の機能拡張として「税金比較」タブを追加。

**主な機能**:
1. NISA vs 特定口座の手取り金額比較
2. 積み上げ棒グラフで税金を視覚化
3. 節税額の強調表示
4. 年次推移グラフで差額の拡大を表示

**技術スタック**: Next.js 14+, React 19, TypeScript, Chart.js, bun（001 と同じ）

**入力ドキュメント**: `aidlc-docs/requirements/requirement-002-nisa-tax-comparison.md`

### Phase 4: エッジケースとエラーハンドリング
- [x] **Step 4.1**: エッジケースを列挙
  - ✅ **ケース1**: 運用益がマイナス（元本割れ）の場合
    - 税金は 0円（マイナス利益には課税されない）
    - NISA も特定口座も手取りが同じ
    - 節税額は 0円

  - ✅ **ケース2**: 運用益が 0円の場合（利回り 0%）
    - 税金は 0円
    - NISA も特定口座も手取りが同じ（元本のみ）
    - 節税額は 0円

  - ✅ **ケース3**: 積立額が非常に大きい場合（月100万円など）
    - 運用益も大きくなり、税金も数千万円単位に
    - グラフの Y軸が自動スケール調整
    - 金額表示が適切にフォーマット（「1,000万円」など）

  - ✅ **ケース4**: 積立期間が短い場合（1年）
    - 運用益が小さく、税金の差も小さい
    - グラフでは差が見えにくい可能性
    - それでも正確な金額を表示

- [x] **Step 4.2**: エラーハンドリングの仕様を明記
  - ✅ 入力値が不正な場合は 001 と同じバリデーション
  - ✅ React Context が未初期化の場合、デフォルト値を使用
  - ✅ グラフ描画エラー時はフォールバック UI を表示
  - ✅ 計算エラー時はエラーメッセージを表示

- [x] **Step 4.3**: バリデーションルールを詳細化
  - ✅ 001 と同じ入力バリデーションを使用
  - ✅ 毎月の積立額: 100円以上
  - ✅ 積立期間: 1年〜40年
  - ✅ 想定年利回り: -10%〜20%
