# 機能仕様: NISA積立シミュレーター

**ブランチ**: `001-nisa-simulator`
**作成日**: 2025-11-17
**ステータス**: Draft
**入力**: User description: "Nisa積立シュミレーターを作成したい"

## Intent（インテント）

### 目的
NISA（少額投資非課税制度）を活用した積立投資の将来シミュレーションを提供し、ユーザーが資産形成の具体的なイメージを持てるようにする。

### 背景
NISA 制度は投資初心者にとって有益な制度だが、「毎月いくら積み立てると、何年後にいくらになるのか」が直感的に分からず、投資を始めるハードルとなっている。シミュレーターにより、具体的な数値を可視化することで、投資への第一歩を後押しする。

### 期待される成果
- **ユーザーにとっての価値**: 毎月の積立額と期間を入力するだけで、将来の資産額を簡単にシミュレーションでき、投資計画を立てやすくなる
- **教育的価値**: 元本と運用益が分かれて表示されることで、複利効果を実感し、長期投資の重要性を理解できる
- **制度理解の促進**: NISA の年間投資上限（つみたて投資枠 120 万円）の活用状況が分かり、制度を最大限活用できる

### 成功した未来の状態
ユーザーが「毎月 3 万円、20 年間、年利 5% で積み立てると約 1,233 万円になる」という具体的な数値を確認し、「これなら自分にもできそう」と投資を始める決断ができるようになった。NISA 制度の非課税枠を意識した積立計画を立てられるようになり、資産形成の第一歩を踏み出すユーザーが増えた。

## ユーザーストーリーとテスト（必須）

### User Story 1 - 基本的な積立シミュレーション (Priority: P1)

ユーザーは毎月の積立額と積立期間を入力し、想定利回りを設定することで、将来の資産額を確認できます。元本と運用益が分かれて表示されるため、投資効果を実感できます。

**この優先度の理由**: NISA積立シミュレーターの最も基本的な機能であり、これだけでもユーザーに価値を提供できます。将来の資産形成をイメージすることで、投資を始めるきっかけになります。

**独立検証方法**: 毎月3万円、20年間、年利5%を入力して「計算する」ボタンを押すことで、正しい将来資産額（約1,233万円）が表示されることを確認できます。

**Acceptance Scenarios**:

1. **Given** ユーザーがシミュレーター画面を開いている、**When** 毎月の積立額「30,000円」、積立期間「20年」、想定年利「5%」を入力して計算ボタンを押す、**Then** 将来資産額、元本合計、運用益が表示される
2. **Given** ユーザーがシミュレーション結果を確認している、**When** 異なる積立額や期間に変更して再計算する、**Then** 即座に新しい結果が表示される
3. **Given** ユーザーが積立額に「0円」を入力した、**When** 計算ボタンを押す、**Then** 入力エラーメッセージが表示され、正しい値の入力を促される

---

### User Story 2 - NISA投資枠の活用状況表示 (Priority: P2)

ユーザーは入力した積立プランがNISA制度の年間投資上限（つみたて投資枠：年間120万円）をどの程度活用しているかを確認できます。枠を超過する場合は警告が表示されます。

**この優先度の理由**: NISA制度を最大限活用するための重要な情報を提供します。ユーザーが非課税枠を使い切れているか、または超過していないかを把握できます。

**独立検証方法**: 毎月10万円の積立を入力した場合、年間投資額120万円がつみたて投資枠の上限に達していることが表示され、この機能が独立して動作することを確認できます。

**Acceptance Scenarios**:

1. **Given** ユーザーが毎月5万円の積立を設定した、**When** シミュレーション結果を確認する、**Then** 年間投資額60万円と、つみたて投資枠120万円の50%活用と表示される
2. **Given** ユーザーが毎月12万円の積立を設定した、**When** シミュレーション結果を確認する、**Then** 年間投資額144万円と、投資枠超過の警告メッセージが表示される

---

### User Story 3 - 運用シナリオ比較 (Priority: P3)

ユーザーは複数の想定利回り（例：保守的3%、標準5%、楽観的7%）で同時にシミュレーションを実行し、結果を比較できます。これにより、リスクとリターンの関係を理解できます。

**この優先度の理由**: より高度な資産計画を立てたいユーザーに価値を提供します。異なるシナリオを比較することで、現実的な期待値を持つことができます。

**独立検証方法**: 毎月3万円、20年間の条件で、3%、5%、7%の3つのシナリオを選択すると、それぞれの将来資産額が並んで表示されることを確認できます。

**Acceptance Scenarios**:

1. **Given** ユーザーが基本条件（毎月3万円、20年）を入力した、**When** 「複数シナリオ比較」を選択し、3つの利回り（3%, 5%, 7%）を設定する、**Then** 3つの結果が並んで表示され、違いが一目で分かる
2. **Given** ユーザーが複数シナリオの結果を見ている、**When** グラフ表示に切り替える、**Then** 3本の曲線が1つのグラフに表示され、成長の違いが視覚的に分かる

---

### エッジケース

- 積立額が極端に大きい（月100万円以上）場合、NISA枠を大幅に超過する警告を表示する
- 積立期間が40年以上の長期設定の場合でも、正確に計算できる
- 想定利回りがマイナス（元本割れシナリオ）の場合、適切に計算し警告を表示する
- 小数点以下の入力（例：33,333.33円）を受け付け、計算に反映する
- 計算結果が非常に大きな金額（億単位）になる場合も、読みやすい形式で表示する

## 要件（必須）

### 機能要件

- **FR-001**: システムは毎月の積立額を入力できなければならない（最小値：100円、最大値：制限なし）
- **FR-002**: システムは積立期間を年単位で入力できなければならない（最小値：1年、最大値：40年）
- **FR-003**: システムは想定年利回りを設定できなければならない（範囲：-10%〜20%、初期値：5%）
- **FR-004**: システムは複利計算により将来の総資産額を算出しなければならない
- **FR-005**: システムは計算結果として「総資産額」「元本合計」「運用益」を明確に区別して表示しなければならない
- **FR-006**: システムは年間投資額を計算し、NISA制度のつみたて投資枠（年間120万円）との比較を表示しなければならない
- **FR-007**: システムは年間投資額がNISA枠を超過する場合、警告メッセージを表示しなければならない
- **FR-008**: システムは入力値が不正な場合（負の数、範囲外など）、エラーメッセージを表示し計算を実行しないようにしなければならない
- **FR-011**: システムはバックエンドやデータベースを必要とせず、フロントエンドのみで完結しなければならない
- **FR-012**: システムはページリロード時に入力データと計算結果がリセットされる（永続化なし）
- **FR-009**: システムは計算結果を数値とグラフ（積立額の推移）の両方で表示できなければならない
  - グラフは元本累計と総資産額を 2 本の線グラフで表示
  - X 軸は期間（経過月数または経過年数）、Y 軸は金額（円）
  - 元本と総資産額を色分けして区別できるようにする
- **FR-010**: システムは複数の利回りシナリオ（最大3つ）を同時に比較できなければならない
- **FR-013**: システムはデスクトップでは 2 カラムレイアウト（左: 入力、右: 結果）、モバイルでは 1 カラムレイアウト（上: 入力、下: 結果）でレスポンシブに表示しなければならない

### Key Entities

- **積立プラン**: 毎月の積立額、積立期間（年数）、想定年利回りを含む設定情報
- **シミュレーション結果**: 総資産額、元本合計、運用益、年間投資額、NISA枠活用率を含む計算結果
- **シナリオ**: 特定の利回り設定と、それに基づく計算結果のセット

## 成功基準（必須）

### 測定可能なアウトカム

- **SC-001**: ユーザーは3ステップ以内（積立額入力 → 期間・利回り設定 → 計算実行）でシミュレーション結果を確認できる
- **SC-002**: 計算結果が1秒以内に表示され、ユーザーが待たされることなく即座に結果を確認できる
- **SC-003**: NISA投資枠の活用状況が一目で分かり、枠の使用率や超過状況を理解するのに5秒以内で済む
- **SC-004**: グラフ表示により、元本と運用益の推移を視覚的に理解でき、ユーザーの90%が数値だけの場合と比べて理解しやすいと感じる
- **SC-005**: 複数シナリオ比較機能により、異なる利回りでの結果の違いを直感的に比較でき、投資判断の参考になる

## 前提条件（任意）

### 前提条件

- NISA制度は2024年以降の新NISA制度（つみたて投資枠：年間120万円、成長投資枠：年間240万円、生涯投資枠：1,800万円）を前提とする
- 本シミュレーターはつみたて投資枠のみを対象とし、成長投資枠は含まない
- 積立は毎月1回、月末に実施されるものとする
- 利回りは年利で一定とし、変動は考慮しない（ユーザーがシナリオ比較で確認可能）
- 税金や手数料は考慮せず、NISA制度内での非課税運用を前提とする
- 計算式は複利計算の標準的な公式を使用する：FV = PMT × ((1 + r)^n - 1) / r（FV: 将来価値、PMT: 毎月の積立額、r: 月利、n: 積立回数）

## Clarifications

### Session 2025-11-18

- Q: このシミュレーターをどのプラットフォームで提供しますか？ → A: Web アプリケーション（ブラウザで動作、React/Vue など）- デスクトップ・モバイル両対応
- Q: 計算結果やユーザー入力をどのように扱いますか？ → A: 完全にステートレス（ページリロードで入力・結果がリセット）- バックエンド不要
- Q: FR-009 でグラフ表示が必要とされていますが、どのグラフライブラリを使用しますか？ → A: Chart.js（軽量、シンプル、豊富なドキュメント）- 折れ線グラフに最適
- Q: FR-009 のグラフで表示する内容を明確にしたいです。グラフの X 軸・Y 軸は何を表示しますか？ → A: 元本と運用益を分離（X軸: 期間、Y軸: 金額）- 2本の線グラフで明確に区別
- Q: 入力フォームと結果表示のレイアウトをどのように設計しますか？ → A: 2カラムレイアウト（左側に入力フォーム、右側に結果表示）- デスクトップに最適
- Q: 具体的な技術スタックは？ → A: React + Next.js（フレームワーク）+ bun（パッケージマネージャー/ランタイム）

## Technical Context

### Platform & Architecture
- **プラットフォーム**: Web アプリケーション（ブラウザベース）
- **対応デバイス**: デスクトップ・モバイル両対応（レスポンシブデザイン）
- **技術スタック**:
  - **フロントエンド**: React 18+
  - **フレームワーク**: Next.js 14+（App Router）
  - **パッケージマネージャー**: bun
  - **ランタイム**: bun（開発時）、Node.js（本番デプロイ時の選択肢）
- **グラフライブラリ**: Chart.js + react-chartjs-2（React ラッパー）
- **UI レイアウト**:
  - デスクトップ: 2カラムレイアウト（左側に入力フォーム、右側に結果表示）
  - モバイル: 1カラムレイアウト（上部に入力フォーム、下部に結果表示）
  - レスポンシブ対応でブレークポイント切り替え
- **グラフ仕様**:
  - X 軸: 期間（経過月数または経過年数）
  - Y 軸: 金額（円）
  - 表示内容: 元本累計と総資産額の 2 本の線グラフで明確に区別
  - 凡例: 元本（青）、総資産額（緑）など色分けして表示
- **データ永続化**: なし（完全にステートレス、バックエンド不要）
- **レンダリング方式**: クライアントサイドレンダリング（CSR）- 計算はブラウザで実行
- **ホスティング**: Vercel 推奨（Next.js ネイティブサポート）、または静的エクスポート

## Scope *(optional)*

### 対象範囲

- 新NISA制度のつみたて投資枠に特化したシミュレーション機能
- 毎月定額の積立シミュレーション
- 複利計算による将来資産額の算出
- グラフによる視覚化
- 複数シナリオの比較機能

### 対象外

- 成長投資枠やジュニアNISA、旧NISA制度のシミュレーション
- ボーナス月の増額設定
- 実際の金融商品（投資信託、株式など）の推奨や選択
- リアルタイムの市場データ連携
- ユーザーアカウント管理や履歴保存機能
- 実際の投資実行や金融機関との連携
