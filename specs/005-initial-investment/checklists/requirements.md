## User Story 修正履歴

**2025-11-19 修正**: P1 と P2 を統合
- **修正前**: P1（入力）、P2（シミュレーション反映）、P3（リセット）
- **修正後**: P1（設定とシミュレーション反映）、P2（リセット）
- **理由**: 入力だけでは価値を提供できず、シミュレーション反映も入力がなければ動作しないため、両者は分離できない一つの機能である。これにより Constitution の "IV. Independent User Stories" に準拠
