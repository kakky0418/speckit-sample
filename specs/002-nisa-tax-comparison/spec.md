# 機能仕様: NISA vs 特定口座 税金比較機能

**ブランチ**: `002-nisa-tax-comparison`
**作成日**: 2025-11-18
**ステータス**: Draft
**入力**: User description: "特定口座で発生する20%の税がNisaだとかからないです。それがひと目でわかるようなグラフを作成しましょう！"

## Intent（インテント）

### 目的
NISA（少額投資非課税制度）の最大のメリットである**非課税効果**を、特定口座との比較を通じて具体的な金額で視覚化し、ユーザーが NISA の節税効果を直感的に理解できるようにする。

### 背景
- NISA 制度は「税金がかからない」とは知っていても、**具体的にいくら得するのか**が分かりにくい
- 特定口座では運用益に対して **20.315% の税金**が課される
- 長期運用では税金の差が数百万円単位になるが、その金額が見えないため NISA の価値を実感しにくい
- 投資初心者が NISA 口座開設の判断材料として、具体的な節税額を知りたい

### 期待される成果
- **ユーザーにとっての価値**: NISA の節税効果を具体的な金額（例: 「200万円お得」）で確認でき、NISA 口座開設の動機付けになる
- **教育的価値**: 税金が運用成績に与える影響を視覚的に理解でき、長期投資における税制優遇の重要性を学べる
- **意思決定の支援**: NISA と特定口座のどちらを選ぶべきか、データに基づいて判断できる

### 成功した未来の状態
ユーザーが「毎月 3 万円、20 年間、年利 5% で積み立てた場合、NISA なら税金 0 円だが、特定口座だと約 104 万円の税金がかかり、手取りが 104 万円少なくなる」という具体的な数値を確認し、「NISA 口座を絶対開設しよう！」と確信を持って行動できるようになった。税金の差額を視覚的に理解し、NISA 制度の価値を実感するユーザーが増えた。

## ユーザーストーリーとテスト（必須）

### User Story 1 - 節税額の視覚的確認 (Priority: P1)

ユーザーは基本シミュレーションで入力した条件（積立額、期間、利回り）を基に、NISA と特定口座の税金の差を具体的な金額とグラフで確認できます。節税額が強調表示され、NISA のメリットが一目で分かります。

**この優先度の理由**: NISA の最大のメリット（非課税）を視覚化する最重要機能です。具体的な金額で示すことで、ユーザーの投資判断を強力に支援します。

**独立検証方法**: 毎月3万円、20年間、年利5%を入力して「税金比較」タブをクリックすることで、節税額（約104万円）が大きく表示され、NISA のメリットが明確に分かることを確認できます。

**Acceptance Scenarios**:

1. **Given** ユーザーが基本シミュレーションで条件を入力済み（例: 毎月3万円、20年、年利5%）、**When** 「税金比較」タブをクリックする、**Then** 💰 アイコン付きで「NISA の節税効果」というタイトルと具体的な節税額（例: 「1,041,895円」）が大きく表示される
2. **Given** 税金比較タブが表示されている、**When** ページを確認する、**Then** NISA の手取り総資産（例: 12,330,000円）と特定口座の手取り総資産（例: 11,288,105円）、差額（例: △1,041,895円）が明示される
3. **Given** ユーザーが基本シミュレーションで条件を入力済み、**When** 「税金比較」タブをクリックする、**Then** 入力条件（積立額、期間、利回り）がそのまま引き継がれ、React Context 経由でデータが共有され、ページ遷移が即座に完了する（< 500ms）

---

### User Story 2 - 詳細な税金比較グラフ (Priority: P1)

ユーザーは4種類のグラフ（節税額強調、手取り比較、積み上げ棒グラフ、年次推移グラフ）で多角的に税金の差を理解できます。視覚的に NISA と特定口座の違いが明確になります。

**この優先度の理由**: 数値だけでなくグラフで表示することで、直感的な理解を促進します。複数のグラフで多角的に比較できることが重要です。

**独立検証方法**: 税金比較タブで4種類のグラフ（積み上げ棒グラフ、年次推移グラフなど）が正しく表示され、各グラフで NISA と特定口座の差が視覚的に分かることを確認できます。

**Acceptance Scenarios**:

1. **Given** 税金比較タブが表示されている、**When** 積み上げ棒グラフを確認する、**Then** 以下が表示される: NISA [元本（青）][運用益（緑）]、特定口座 [元本（青）][運用益（暗緑）][税金（赤）]、各セクションにマウスホバーで金額が表示され、凡例が表示される
2. **Given** 税金比較タブが表示されている、**When** 年次推移グラフを確認する、**Then** X軸: 年数（0年〜20年）、Y軸: 総資産額（手取り）、青線: NISA の手取り総資産、赤線: 特定口座の手取り総資産、2本の線の差が年々開いていく様子が視覚化され、凡例が表示される
3. **Given** 税金比較タブが表示されている、**When** 詳細内訳テーブルを確認する、**Then** 元本合計、運用益（税引前）、税金（20.315%）、手取り運用益、総資産（手取り）が NISA と特定口座で並列表示される

---

### User Story 3 - エッジケースの適切な処理 (Priority: P2)

システムは運用益がマイナス（元本割れ）や0%の場合でも、適切に税金を計算し、ユーザーに分かりやすく表示します。

**この優先度の理由**: 現実的なシナリオ（相場下落時など）でもシステムが正しく動作することで、ユーザーの信頼を獲得します。

**独立検証方法**: 利回り -3% や 0% を入力し、税金比較タブで税金が 0円 と表示され、NISA と特定口座の手取り総資産が同じになることを確認できます。

**Acceptance Scenarios**:

1. **Given** ユーザーがマイナス利回り（例: -3%）を入力した、**When** 税金比較タブを表示する、**Then** 運用益がマイナスの場合、税金は 0円 と表示され、NISA も特定口座も手取り総資産が同じになり、節税額は 0円 と表示される
2. **Given** ユーザーが利回り 0% を入力した、**When** 税金比較タブを表示する、**Then** 税金は 0円 と表示され、NISA も特定口座も手取り総資産が同じ（元本のみ）になり、節税額は 0円 と表示される

---

### エッジケース

- 運用益がマイナス（元本割れシナリオ）の場合、税金は 0円 として計算する
- 運用益が 0円 の場合、税金は 0円 として計算する
- 非常に大きな積立額（月100万円以上）の場合でも、税金計算が正確に行われる
- 積立期間が40年など長期の場合でも、年次推移グラフが適切に表示される

## 要件（必須）

### 機能要件

- **FR-001**: システムは NISA と特定口座の手取り総資産を並列表示しなければならない
- **FR-002**: システムは NISA の節税額を具体的な金額（円単位）で強調表示しなければならない
- **FR-003**: システムは積み上げ棒グラフで元本・運用益・税金を色分けして表示しなければならない（NISA: 元本（青）+ 運用益（緑）、特定口座: 元本（青）+ 運用益（暗緑）+ 税金（赤））
- **FR-004**: システムは年次推移グラフで NISA と特定口座の手取り総資産を折れ線グラフで表示しなければならない（X軸: 年数、Y軸: 金額）
- **FR-005**: システムは詳細内訳テーブルで元本合計、運用益（税引前）、税金（20.315%）、手取り運用益、総資産（手取り）を表示しなければならない
- **FR-006**: システムは基本シミュレーションページから「税金比較」タブで遷移できなければならない
- **FR-007**: システムは基本シミュレーションで入力した条件（積立額、期間、利回り）を税金比較ページに引き継がなければならない（React Context または URL パラメータ）
- **FR-008**: システムは税率 20.315% を正確に適用して税金を計算しなければならない
- **FR-009**: システムは運用益がマイナスまたは 0 の場合、税金を 0円 として計算しなければならない
- **FR-010**: システムはレスポンシブデザインに対応し、モバイルでも4つのグラフが縦スクロールで閲覧できなければならない
- **FR-011**: システムは計算結果を 1秒以内に表示し、グラフを 500ms 以内に描画しなければならない

### Key Entities

- **税金比較結果**: NISA の手取り総資産、特定口座の手取り総資産、税金額、節税額を含むデータ
- **年次推移データ**: 各年における NISA と特定口座の手取り総資産の配列
- **詳細内訳**: 元本合計、運用益（税引前）、税金、手取り運用益、総資産（手取り）の詳細情報

## 成功基準（必須）

### 測定可能なアウトカム

- **SC-001**: ユーザーは基本シミュレーション結果から1クリックで税金比較ページに遷移でき、即座に節税額を確認できる
- **SC-002**: 節税額が大きく強調表示され、ユーザーが5秒以内に NISA のメリットを理解できる
- **SC-003**: 4種類のグラフが同時に表示され、多角的に税金の差を比較できる
- **SC-004**: 税金計算が正確で、税率 20.315% が正しく適用される
- **SC-005**: エッジケース（運用益マイナス、0%）でもエラーなく適切に表示される

## 前提条件（任意）

### 前提条件

- 税率は特定口座の標準税率 20.315%（所得税 15.315% + 住民税 5%）を使用する
- NISA 制度では運用益に税金がかからない（税率 0%）
- 計算対象は運用益のみで、配当金・分配金の税金は考慮しない
- 確定申告による還付や損益通算は考慮しない
- 001-nisa-simulator の基本シミュレーション機能が実装済みであることを前提とする
- 001 と同じ計算ロジック（複利計算）を使用する
- 基本シミュレーションで入力された条件を共有するため、React Context API を使用する

## Clarifications

### Session 2025-11-18

- Q: この機能は 001 の一部として実装しますか、それとも独立したプロジェクトですか？ → A: 独立したプロジェクト（002-nisa-tax-comparison）として管理するが、技術的には 001 のコードベースを拡張する形で実装する
- Q: グラフは何種類表示しますか？ → A: 4種類（節税額強調表示、手取り比較、積み上げ棒グラフ、年次推移グラフ）を並列表示
- Q: 001 からのデータ共有方法は？ → A: React Context API を使用して、積立額、期間、利回りを共有する
- Q: 税率は変更可能にしますか？ → A: 固定（20.315%）で良い。将来的に変更可能にする場合は別途検討
- Q: モバイル対応は必要ですか？ → A: 必要。4つのグラフを縦スクロールで閲覧できるようにする

## Technical Context

### Platform & Architecture
- **プラットフォーム**: Web アプリケーション（ブラウザベース）
- **対応デバイス**: デスクトップ・モバイル両対応（レスポンシブデザイン）
- **技術スタック**:
  - **フロントエンド**: React 19+
  - **フレームワーク**: Next.js 14+（App Router）
  - **パッケージマネージャー**: bun
  - **ランタイム**: bun（開発時）、Node.js（本番デプロイ時の選択肢）
- **グラフライブラリ**: Chart.js + react-chartjs-2（React ラッパー）
- **状態管理**: React Context API（基本シミュレーションと税金比較でデータ共有）
- **新規ページ**: `app/tax-comparison/page.tsx`
- **新規コンポーネント**:
  - `components/TaxSavingsHighlight.tsx` - 節税額強調表示
  - `components/TaxComparisonBarChart.tsx` - 積み上げ棒グラフ
  - `components/TaxComparisonLineChart.tsx` - 年次推移グラフ
  - `components/TaxDetailTable.tsx` - 詳細内訳テーブル
- **拡張ファイル**:
  - `lib/calculator.ts` に `calculateTaxComparison()` 関数を追加
  - `lib/types.ts` に `TaxComparisonResult` 型を追加
  - `contexts/InvestmentPlanContext.tsx` を追加（データ共有用）
  - `app/layout.tsx` に Context Provider を追加
- **計算ロジック**:
  ```typescript
  interface TaxComparisonResult {
    nisa: {
      totalAssets: number;
      tax: number;  // 常に 0
      netAssets: number;
    };
    tokutei: {
      totalAssetsBeforeTax: number;
      tax: number;  // 運用益 × 0.20315
      netAssets: number;
    };
    taxSavings: number;  // nisa.netAssets - tokutei.netAssets
  }
  ```
- **データ永続化**: なし（完全にステートレス、バックエンド不要）
- **レンダリング方式**: クライアントサイドレンダリング（CSR）- 計算はブラウザで実行
- **ホスティング**: Vercel 推奨（Next.js ネイティブサポート）、または静的エクスポート

## Scope *(optional)*

### 対象範囲

- NISA vs 特定口座の税金比較機能
- 節税額の具体的な金額表示
- 4種類のグラフによる視覚化（節税額強調、手取り比較、積み上げ、年次推移）
- 詳細内訳テーブルの表示
- 001 からのデータ共有とページ遷移

### 対象外

- 新 NISA の成長投資枠との比較
- 配当金・分配金の税金計算
- 確定申告による還付や損益通算のシミュレーション
- 実際の金融機関への口座開設案内
- 税率の変更機能（固定 20.315%）
- 旧 NISA 制度（つみたて NISA、一般 NISA）との比較
